TabSwitch — Tab Manager Privacy Policy

Last updated: May 24, 2026

TabSwitch — Tab Manager is a Chrome extension that helps you switch between and manage open tabs — including search, site grouping, mute/unmute audio, pause/play videos, and batch tab closing. We respect your privacy. This policy explains what data TabSwitch — Tab Manager handles and how.

Data Collection

TabSwitch — Tab Manager does not collect, transmit, or sell any personal data. We do not use analytics, advertising, or third-party tracking SDKs.

Local Data Only

  • Tab titles and URLs are read from Chrome's tabs API solely to display them in the switcher overlay. This information stays in your browser's memory and is never sent to any server.
  • User preferences (window scope, language, MRU sort order, etc.) are stored locally using chrome.storage on your device.
  • Screenshot previews (if you enable this optional feature) are cached in chrome.storage.session and cleared when you close the browser.

Permissions

TabSwitch — Tab Manager requests only the permissions needed for tab switching, tab management, and media control. Scripts are injected only when you press the keyboard shortcut or click the toolbar icon. The activeTab permission lets TabSwitch — Tab Manager capture the currently active tab after you invoke the extension. If you enable screenshot previews, Chrome asks for optional access to regular web pages (http://*/* and https://*/*) so TabSwitch — Tab Manager can cache local thumbnails for tabs you visit.

隐私政策（简体中文）

TabSwitch — 标签页管理是一款帮助您快速切换与管理 Chrome 标签页的扩展程序，支持搜索、按网站分组、 静音/暂停音视频及批量关闭标签页。我们重视您的隐私。

数据收集

TabSwitch — 标签页管理 不收集、不传输、不出售任何个人数据。 我们不使用分析工具、广告或第三方追踪 SDK。

仅本地存储

  • 标签页标题和 URL 仅通过 Chrome tabs API 读取，用于在切换器浮层中展示。 这些信息保留在浏览器内存中，不会发送到任何服务器。
  • 用户设置（窗口范围、语言、MRU 排序等）通过 chrome.storage 存储在您的本机。
  • 截图预览（可选功能）缓存在 chrome.storage.session 中，关闭浏览器后自动清除。

权限说明

TabSwitch — 标签页管理仅请求标签页切换、标签页管理和媒体控制所需的权限。 脚本仅在您按下快捷键或点击工具栏图标时注入。 activeTab 权限仅允许 TabSwitch — 标签页管理在您主动调用扩展后截取当前活动标签页。 如果您开启截图预览，Chrome 会请求普通网页的可选访问权限（http://*/* 和 https://*/*），用于为您访问过的标签页在本地缓存缩略图。
